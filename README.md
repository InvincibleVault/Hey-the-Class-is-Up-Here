# Hey, The Class is Up Here!
This is a repository for the 2026/2027 Capstone I and II 


## Game Design
This is a co-op game between a 3D player in virtual reality and a 2D player on a monitor.
The monitor player will be playing on a 2D slice of the 3D world.
The VR player can grab the 2D player's plane and move it around, granting them access to
places the 3D player cannot go. Both players will have incomplete information at times, meaning
they have to communicate to solve puzzles.
